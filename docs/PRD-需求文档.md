# 需求文档（PRD）— 小年的玩具屋

> 文档状态：v1.0 草案，待设计评审
> 最后更新：2026-08-17

## 1. 产品概述

### 1.1 一句话定位
一款帮助 0~3 岁宝宝父母「管理家中玩具、按专业育儿依据安排'每天玩什么、怎么陪玩'」的本地化工具。

### 1.2 目标用户
- **核心用户**：0~3 岁宝宝的父母/照护者（爸爸、妈妈、祖辈）。
- **单宝宝模式**：本版本只管理一个宝宝档案（用户确认为单宝宝）。

### 1.3 核心价值
1. 让父母**充分盘活家中已有的玩具**，避免闲置与盲目购买。
2. 提供**基于月龄的玩法建议与能力锻炼解读**，让每一次陪玩有目标、有依据。
3. 形成**陪伴轨迹**（玩耍历史），帮助父母复盘宝宝的成长与能力分布。

### 1.4 设计约束（用户已确认）
- **技术形态**：纯前端静态网页（单页应用），无需服务器，浏览器打开即用，完全离线可用。
- **图片识别**：不做真实 AI 图像识别；采用「引导式手动打标签」。
- **育儿依据**：内置规则引擎 + 权威文献解读文案；规则库中每一条推荐均标注来源机构。
- **月龄覆盖**：从出生至 **3 岁（36 个月）**。
- **界面**：纯中文简体；颜色温暖、风格活泼、适配手机竖屏优先、响应式兼顾平板。
- **玩耍提醒**：页面内提示音 + 视觉横幅 + 可选浏览器通知（需用户授权）。

## 2. 功能需求

### 2.1 功能一：宝宝基本信息
- 录入并编辑：**宝宝昵称（默认"小年"）、性别、出生日期**。
- **月龄自动计算**：根据「当天日期 − 出生日期」动态计算月龄（每满整月显示"X 个月"，不足一个月的显示"X 周或天"），无需手动维护，日期变化自动更新。
- 宝宝信息完善度提示：未填完整时引导首次设置。
- 展示：主页宝宝档案卡（头像占位/昵称/性别/月龄）。

### 2.2 功能二：玩具库与引导式打标签
- **上传图片**：手机拍照/相册选图，前端压缩后（Base64）本地存储；支持删除与替换。
- **引导式打标签**（多步选择，非自由文本——避免拼写不一致）：
  1. **玩具类型**（带 emoji 图标，单选，如：安抚/牙胶、视觉听觉玩具、堆叠构建、推拉运动、拼插积木、角色扮演、涂画手工、音乐乐器、绘本阅读、户外运动等）。
  2. **锻炼能力维度**（多选，7 大维度：大运动、精细动作、感官、语言、认知、社交情绪、创造力）。
  3. **适配月龄区间**（双滑块指定 min~max 月）。
  4. 可选**备注**（戒玩/偏好等自由文本）。
- **即时解读回显**：选择完类型与能力后，系统实时显示该能力在当前月龄段的发育依据解读文案。
- **玩具卡片列表**：缩略图 + 能力标签 + 适配月龄；支持按能力维度筛选、排序。

### 2.3 功能三：玩耍计划、陪伴与提醒
- **今日推荐**：根据宝宝**当前月龄**与玩具库，自动选出「当前最该玩」的 1~3 个玩具：
  - 优先选「适配区间覆盖当前月龄」的玩具；
  - 覆盖不同能力维度，避免连续重复；
  - 结合玩耍历史，偏向近段时间锻炼较少的能力维度（补齐短板）。
- **玩法讲解**：每个推荐玩具给出：锻炼目标、怎么陪玩（家长话术式引导）、建议专注时长。
- **专注计时器**：进入"开始玩耍"后开始倒计时，到点**提示音 + 横幅 + 可选浏览器通知**提醒"该切换玩具啦"。
- **玩耍记录**：玩耍结束可记录本次陪玩了哪些玩具、各投入时长，写入历史；历史用于复盘与后续推荐。
- **计划依据解读**：每次生成推荐时附"为什么要这样安排"的育儿解读文案，并标注依据来源机构。

## 3. 数据模型（草案）

### 宝宝档案 `babyProfile`
| 字段 | 类型 | 说明 |
|---|---|---|
| nickname | string | 昵称，默认"小年" |
| gender | 'male'\|'female'\|'' | 性别 |
| birthDate | date\|null | 出生日期，月龄由它动态算出 |

### 玩具 `toy`
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 唯一 ID |
| name | string | 名称 |
| imageData | string\|null | 压缩后的 Base64 图片 |
| type | string | 玩具类型（枚举） |
| skills | string[] | 能力维度（7 大维度子集） |
| ageMin, ageMax | int | 适配月龄区间（0~36） |
| note | string | 可选备注 |
| createdAt | date | 添加时间 |

### 玩耍记录 `playLog`
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 唯一 ID |
| toyId | string | 玩的玩具 |
| minutes | int\|null | 投入分钟 |
| playedAt | date | 时间 |
| comment | string | 可选记录/心情 |

### 设置 `settings`
- 声音开关、浏览器通知授权状态、首次引导完成标记、数据时间戳。

## 4. 非功能需求

1. **性能**：图片压缩后存储（单张 ≤ 约 300KB），列表流畅；IndexedDB 存储，localStorage 存轻量设置。
2. **离线**：完全离线可用；数据仅存本地，无网络上传。
3. **隐私**：全部数据本地持久化，支持导出/导入 JSON 备份（防丢失/换机）。
4. **安全性**：纯前端，无账号系统；数据备份可手动导出。
5. **可用性**：大按钮、大字号、首页一屏可达核心操作；移动端手势友好。
6. **健壮性**：图片解码失败、存储满的降级提示；首次使用引导。

---

## 5. 界面要求（用户确认）
- 颜色温暖（奶油底 + 暖橙/珊瑚粉点缀）、活泼（圆角、卡通 SVG 元素、微动效）。
- 移动端竖屏优先，底部 Tab 导航（首页/玩具库/玩耍计划/我的）。
- 响应式适配平板与横屏。

---

## 6. 验收标准
1. 能新建/编辑宝宝档案，月龄随日期自动变化。
2. 能添加玩具图片并完成引导式打标签，获得能力解读。
3. 能生成今日推荐计划，且每个推荐含锻炼目标、玩法、建议时长与依据来源。
4. 玩耍计时到点有声音+横幅+（授权后）浏览器通知提醒。
5. 玩耍历史被记录并可复盘；历史影响后续推荐。
6. 数据可导出/导入备份。
7. 界面在竖屏手机展示美观、可用；完全离线可运行。

---

## 7. 范围外（本版本不做）
- 真实 AI 图像识别。
- 多宝宝管理。
- 多设备云同步（仅导出/导入 JSON 备份）。
- 系统级推送通知（浏览器限制，仅页面级提醒）。
